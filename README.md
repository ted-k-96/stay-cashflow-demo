# stay-cashflow-demo

숙박업 현금흐름과 채널 수수료 정산을 미리 계산해 보는 **개인 포트폴리오용 데모**입니다.

- 모든 데이터는 직접 만든 **더미 데이터**입니다. 실제 사업자·예약·금액과 무관합니다.
- 특정 회사의 내부 자료, 코드, API를 사용하지 않았습니다. 공개된 예시 화면을 참고한 목업이며, 특정 회사와 관련이 없습니다.
- 수수료율, 입금 기준일, 수수료 발행일 등 `*` 표시 값은 확인하지 못해 임의로 정한 예시입니다.

## 보는 법

`index.html`을 브라우저로 열면 됩니다. 설치나 서버가 필요 없습니다.

1. **현금흐름** 탭: 날짜별 입금·지출 예정, 월말 예상 잔고, 달력 날짜를 누르면 그날의 내역
2. 같은 탭 아래: **수수료 정산 확인서**(예약 건별 계산표)와 **세금계산서 발행 입력 예시**
3. **규칙·입력** 탭: 채널별 수수료율, 입금 기준일(체크인/체크아웃), 발행일 등을 바꾸면 화면이 다시 계산됩니다
4. 정산 확인서·발행 입력 예시 카드의 **엑셀 저장**: 같은 구성의 `.xlsx` 파일이 받아집니다

## 한계

- 실제 채널 연동, 실제 입금 비교는 하지 못했습니다.
- 발행 입력 예시는 세금계산서가 아니며, 공급가액·세액 분리(10%)는 가정입니다. 실제 발행 방식은 채널·계약마다 다릅니다.
